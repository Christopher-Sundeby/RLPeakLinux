# RLPeak Attribution Notes

## Attribution summary

- RocketStats was originally created by the RocketStats team and contributors.
- RLPeak re-integrates a RocketStats-style overlay experience through built-in RLPeak runtime code.
- RLPeak does not bundle or execute BakkesMod runtime/plugin binaries.

## Overlay font/theme assets

- Bundled overlay font assets currently include:
  - `public/overlay-themes/rocketstats-circle/fonts/Azonix.otf`
  - `public/overlay-themes/rocketstats-JSTKISS/fonts/MADETommy.otf`
  - `public/overlay-themes/rocketstats-NativeTheme/fonts/font.otf`
  - `public/overlay-themes/minimalist/fonts/Minecraft.otf`
- Before public redistribution, verify each font's redistribution/license terms and include upstream notices when required.


## RocketStats themes and assets

Some overlay theme assets are based on or inspired by RocketStats themes.
